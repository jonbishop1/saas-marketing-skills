# Comparison and battlecard templates

Matrix columns: criterion / why it matters for this task / our evidence / alternative evidence / known limitation / verification status.

Battlecard fields: prospect context / alternative / discovery question / defensible difference / proof asset / concession / next evaluation step.

## Fictional application

A local request replay tool competes with log search and an internal script. Its useful difference may be repeatable replay, but logging remains better for broad incident search. Ask whether the evaluator needs reconstruction or discovery before proposing a switch.

A managed ingestion tool competes with scheduled SQL and a self-hosted connector. Compare operator time and recovery behavior alongside runtime cost. A hosted price alone cannot support a total-cost claim if internal operating effort is unknown.

## Public comparison gate

Check every externally verifiable cell against primary sources or recorded tests. Publish a scope sentence explaining the workload and exclusions. Give the competitor's appropriate use case. If a cell is unknown, leave it unknown and describe how to verify it.
