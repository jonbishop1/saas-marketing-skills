# Event operating sheet

Objective / target task and role / useful asset / owner / cost ceiling / expected capacity / evidence of audience fit / agreed next action / follow-up capacity.

## Conversation prompts

“How are you handling [specific task] today?” → “What tends to fail?” → “Which environment does that happen in?” → “Would this example or evaluation checklist help?” → “What follow-up, if any, would be useful?”

## Follow-up draft pattern

Reference the actual conversation, provide the promised artifact, restate a known limitation, and propose the agreed next step. If no permission or next step was agreed, do not invent one.

## Economics

Include travel, fees, preparation, staff time where relevant, and follow-up. Cost per qualified evaluation requires a defined qualification rule and observed evaluations. Do not claim event ROI from attributed pipeline alone.
