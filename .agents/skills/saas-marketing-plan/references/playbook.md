## Forecast transparently

If the inputs exist: qualified visits × evaluation-start rate × meaningful-value rate × paid-conversion rate. Define the denominator and horizon for every rate. Use observed cohorts where possible; otherwise show a scenario range, not a target disguised as a forecast. Include delivery cost when discussing unit economics.

## Fictional sequencing

**Developer tool:** users find a repository but cannot reproduce the example. First repair and verify the evaluation path, then distribute a task tutorial to a relevant community. More visitors would not resolve the current barrier.

**Data product:** demos attract interest but warehouse access blocks evaluation. Prepare an approved slice and least-privilege instructions, then run a focused evaluation offer. Track reconciliation success and approved next steps separately from booked demos.

## Events and partnerships

For an event, define who should attend, the useful conversation or demo, consent-aware capture, follow-up owner, and qualified evaluation outcome. For an integration partner, establish shared users, verified joint workflow, support boundaries, and an authorized distribution plan.
