# Discovery prompts

What changed? What task is failing? What is the current workaround? Who owns it? What would a successful evaluation demonstrate? Who can authorize the environment and data? What evidence does the approver need? What would make this a poor fit?

## Champion memo

Decision / task and baseline / demonstrated result / alternatives / implementation owner and effort / operating cost assumptions / unresolved risks / proposed next step / approvers.

## Fictional handoff

A backend engineer has verified local replay, but platform review is still needed before service integration. State both facts. A data engineer has reconciled one approved slice, but schema-change recovery remains untested. Make that the next bounded evaluation step rather than describing the account as production ready.
