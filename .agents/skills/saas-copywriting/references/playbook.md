# Copy worksheet

Reader / task / current workaround / supported capability / resulting benefit / proof / limitation / next action.

## Fictional developer-tool example

Weak: “Supercharge observability with AI.”

More specific, if verified: “Replay a sanitized HTTP request against your local service.” Supporting copy should explain capture, redaction, supported frameworks, and what is not reproduced. CTA: “Run the local example.”

## Fictional data-product example

Weak: “Real-time, trusted data at any scale.”

More specific, if verified: “Sync changed order records into your warehouse and reconcile the result.” Supporting copy should name supported sources, update behavior, and how freshness is measured. CTA: “Evaluate a sample workload.”

## Email and sales copy

Structure around the recipient's task, a specific useful observation or asset, and a proportionate action. Preserve consent and suppression requirements in delivery workflows. Drafting a sequence does not authorize sending it.
