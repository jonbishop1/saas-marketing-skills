# Contribution brief

Community / relevant task / observed question / current rule source / useful contribution / affiliation disclosure / evidence / next step / reply owner / intended signal.

## Fictional draft opening

“I maintain a request replay tool. We tested a sanitized fixture to understand this failure mode; here is the minimal reproduction and where the method stops working.” Include the actual useful material before an optional product link.

## Data-product alternative

A transparent explanation of late-arrival reconciliation with synthetic records can be useful to an analytics community even if members never use the product. State what is illustrative and what was measured.

## Review rule

If participation generates repeated support requests that the team cannot answer, reduce scope and improve the artifact before increasing distribution. Do not count a removed promotional post as a channel experiment proving lack of demand.
