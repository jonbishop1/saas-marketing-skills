# Audit register

URL / task / check / observation / evidence source / impact / confidence / proposed fix / effort / verification.

## Technical checks

Distinguish blocked crawling, noindex, canonical selection, a missing route, and content unavailable in the tested rendering context. They are different failures with different fixes. Use current official search documentation for directives, structured data, and performance guidance; avoid invented universal thresholds.

## Content checks

A developer quickstart that is indexed but unusable has an evaluation problem as well as a content problem. A data connector page with only swapped product names lacks task-specific substance. Recommend a real worked workflow before scaling such pages.

## Limits and protected pages

Record what was not inspected. Do not alter protected articles, metadata, or authorship as an incidental audit fix. Keep internal audit timestamps in evidence records if useful; do not add reviewed or checked dates to public pages unless explicitly authorized.
