# Activation contract

Actor / account entity / task / prerequisites / observable success / sample-versus-real flag / assisted-versus-independent flag / time origin / failure and recovery / later durable milestone.

## Fictional event paths

**Request replay:** example launched → sanitized sample replay succeeds → own approved request reproduces an issue → project integrated → repeated useful use. Keep sample replay separate from real-project activation.

**Ingestion:** access approved → source connected → initial load → reconciliation passes → incremental update verified → scheduled workload operated by an owner. A connection event does not prove correctness.

## Lifecycle message

Trigger on a meaningful state and offer the next useful action or recovery step. Avoid a generic countdown sequence for users still waiting on administrator approval. Draft messages without sending them unless delivery is authorized.
