# Production patterns

## Tutorial

Result → prerequisites → smallest working path → expected output → why it works → failure recovery → limits → next task. Provide cleanup if resources were created. Name the environment actually tested.

## Comparison

Decision and workload → criteria → sourced differences → appropriate use cases → evaluation instructions. An undocumented feature stays unknown; competitor silence is not proof of absence.

## Case study

Customer permission → baseline and task → change → observed result → measurement window and attribution limits → transferable lesson. If no permission or measured result exists, write a clearly labeled scenario instead.

## Visual decision

A request-replay article can use a sequence showing capture, sanitization, replay, and verification. An ingestion article can show the distinction between arrivals, watermark, and reconciliation. A decorative robot or an invented growth chart does not improve the explanation.

## Repurposing

Preserve the technical caveat and the evidence behind the claim when turning a guide into a post or newsletter. A community derivative should answer a relevant question and disclose affiliation; preparing it does not authorize posting it.
