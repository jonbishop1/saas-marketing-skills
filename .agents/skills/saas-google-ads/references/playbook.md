# Campaign planning worksheet

Intent / queries / exclusions and reasons / ad promise / evaluation path / qualification event / economic outcome / spend cap / review rule.

## Fictional decisions

A request-replay product might exclude “HTTP jobs” but retain a supported framework tutorial query if a working example has historically produced durable users. A data-ingestion product should not bid on an unsupported source just because estimated demand is high.

## Measurement QA

Check event duplication, consent and permitted data flow, account identity, attribution window, conversion lag, and whether a low-value action is being treated as the primary outcome. If offline qualification is delayed, describe the lag rather than declaring an early winner.

## Economics

Scenario qualified-evaluation cost = spend / qualified evaluations. If the denominator is zero, report zero outcomes and the spend; do not invent an efficiency estimate. Revenue efficiency needs the matching cohort, horizon, and delivery costs where relevant.
