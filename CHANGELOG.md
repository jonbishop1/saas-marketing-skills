# Changelog

All notable changes to this project will be documented in this file.

## [2.0.0] — 2026-10-15

### Changed
- Redesigned all 16 existing skills for developer-tool and data-product tasks; retained their directory names for compatibility.
- Replaced long, overlapping reference trees with task-specific playbooks and fictional examples.
- Removed mandatory full intake, arbitrary budget and channel rules, unsupported benchmark defaults, and ambiguous setup/activation metrics.
- Added evidence boundaries, meaningful-value definitions, role-specific evaluation, privacy, and explicit execution scope.
- Updated author links to Jon Bishop and declared the canonical skills directory in the Claude plugin manifest. The legacy marketplace identifier remains compatible.

### Added
- Two standalone product-specific distributions, each with 25 skills, generated by `scripts/export_collections.py`: `devtool-marketing-skills` and `data-product-marketing-skills`.
- 10 skills: README, quickstart, agent readiness, community distribution, data-product evaluation, technical pricing, technical proof, technical sales enablement, conference pipeline, and integration marketing.
- Contribution guidance, deterministic repository validation, validation regression tests, CI, and behavioral evaluation scenarios.

## [1.0.0] — 2026-07-28

### Added
- 16 marketing skills covering audience research, competitive research, SEO research, SEO audit, customer psychology, marketing plan, content strategy, content production, copywriting, landing pages, product launches, Google Ads, Meta Ads, onboarding, data analysis, and shared background intake
- `.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json` for Claude Code plugin directory submission
